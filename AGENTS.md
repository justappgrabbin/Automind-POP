## Work loop — repeat until milestone acceptance
- Inspect real source, document its actual behavior, and preserve hashes/provenance.
- Choose the smallest integration that advances the next acceptance test.
- Implement it using actual source, not a rewritten imitation.
- Run existing and new tests; record commands, outputs, failures, and environment.
- Inject a controlled failure; require detection, recovery, and a new verified result.
- Verify persistence by stopping and restarting the runtime.
- Commit reversible changes on a development branch, update progress and open blockers.
- Continue to the next task without waiting for routine confirmation.
